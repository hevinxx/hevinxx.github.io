문해빈(이하 "운영자")은 모바일 게임 Snow Tail(이하 "게임")을 운영하며, 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 관련 고충을 처리하기 위해 이 처리방침을 둡니다.

시행일: 2026년 11월 17일

## 1. 처리하는 개인정보 항목과 목적

게임은 회원가입이 없습니다. 이름·전화번호·이메일 주소를 요구하지 않습니다.

| 항목 | 수집 시점 | 목적 |
|---|---|---|
| 익명 플레이어 ID, 인증 토큰 | 게임 첫 실행 시 자동 생성 | 온라인 리더보드 접속과 기록 제출 |
| 이용자가 입력한 기록 이름, 점수, 플레이 통계(눈사람 수·최고 콤보·거리·구간·플레이 시간·이어하기 횟수), 눈사람 구성, 게임 모드·날짜, 접수 시각 | 순위에 든 기록을 등록할 때 | 온라인 리더보드 표시 |
| 광고 식별자(ADID/IDFA, 허용한 경우), IP 주소, 기기 정보(모델·OS·언어), 광고 조회·클릭 정보 | 광고를 불러오거나 표시할 때 | 광고 제공, 부정 클릭 방지 |
| 개인정보 동의 상태 | 동의 화면에서 선택할 때 | 동의 결과에 맞는 광고 제공 |
| 구매 거래 ID, 상품 ID | 광고 제거 상품을 구매할 때 | 구매 확인과 복원 |

- 등록한 기록(이름·점수·플레이 통계·눈사람 구성)은 **리더보드에서 모든 이용자에게 공개됩니다.** 실명 등 자신을 알아볼 수 있는 이름을 쓰지 마세요.
- 결제는 Google Play와 App Store가 처리합니다. 운영자는 카드 번호 등 결제 수단 정보를 받지 않습니다.
- 최고 점수, 마지막으로 쓴 이름, 기기 안의 기록 목록은 이용자의 기기에만 저장되며 운영자에게 전송되지 않습니다.

## 2. 보유 기간

| 항목 | 보유 기간 |
|---|---|
| 익명 플레이어 ID | 서비스 종료 시까지 |
| 리더보드 기록 | 해당 리더보드의 상위 100위 안에 있는 동안. 지난 날짜의 "오늘의 산" 리더보드는 서비스 종료 시까지. 이용자가 지우면 즉시 삭제 |
| 눈사람 구성 | 해당 기록이 리더보드에서 밀려나면 즉시 삭제 |
| 광고 관련 정보 | 각 광고 사업자의 정책에 따름 |

보유 기간이 끝나거나 삭제 요청을 받으면 지체 없이 파기합니다. 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

## 4. 개인정보의 국외 이전

게임을 이용하는 동안 1장의 정보가 위 사업자의 서버로 네트워크를 통해 전송됩니다.

- 이전받는 자: Unity Technologies, Google LLC
- 이전 국가: 미국 등 각 사업자의 서버 소재국
- 이전 항목·목적·보유 기간: 1장·2장과 같음
- 이전을 원하지 않으면 게임을 오프라인으로 이용할 수 있습니다. 이 경우 온라인 리더보드와 광고 보상(이어하기)을 이용할 수 없습니다.

## 5. 맞춤형 광고와 거부 방법

광고 사업자는 광고 식별자로 이용자의 관심사에 맞는 광고를 보여 줄 수 있습니다.

- Android: 설정 → Google → 광고 → 광고 ID 삭제
- iOS: 앱이 묻는 "추적 허용" 요청에서 "앱에 추적 금지 요청"을 선택하거나, 설정 → 개인정보 보호 및 보안 → 추적에서 끕니다.
- 게임 타이틀 화면의 "개인정보 설정"에서 광고 동의를 다시 설정할 수 있습니다 (동의가 필요한 지역).

거부해도 광고는 표시되지만, 관심사와 무관한 광고가 됩니다.

## 6. 이용자의 권리와 행사 방법

이용자는 언제든지 개인정보의 열람·정정·삭제·처리 정지를 요구할 수 있습니다.

**기록 삭제**

1. 게임의 리더보드 화면을 엽니다.
2. 이 기기에서 등록한 기록에는 휴지통 아이콘이 보입니다. 아이콘을 누릅니다.
3. "삭제"를 눌러 확인합니다. 기록과 눈사람 구성이 서버에서 즉시 삭제됩니다.

서버는 기록을 등록한 익명 플레이어와 같은 플레이어가 요청할 때만 기록을 삭제합니다. 그래서 다른 사람은 이용자의 기록을 지울 수 없습니다. 게임을 삭제하면 익명 플레이어 ID가 사라지므로, 그 전에 등록한 기록은 이용자와 연결할 수 없어 삭제할 수 없습니다.
