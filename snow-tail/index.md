*Every tail tells a tale.*

눈덩이가 산을 굴러 내려가며 같은 색 눈덩이 3개를 모아 눈사람을 만드는 캐주얼 퍼즐 액션 게임입니다. 한 판은 1~3분입니다.

A casual puzzle-action game: roll down the mountain, collect 3 snowballs of the same color, and build snowmen. Each run takes 1–3 minutes.
